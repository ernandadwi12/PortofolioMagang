Tentang

Halo, saya Ernanda Dwi, mahasiswi Politeknik Elektronika Negeri Surabaya prodi Teknologi Rekayasa Multimedia (TRM) yang tertarik mendalami pengembangan back end.

Saya tertarik memahami bagaimana sebuah aplikasi berjalan di balik tampilannya. Bagi saya, back end adalah bagian yang paling menarik karena di sanalah data diolah, disimpan, dan dikirim ke pengguna. Karena itu saya mulai belajar memahami alur data, merancang database, dan membuat API agar aplikasi berjalan dengan lancar. Saya percaya sistem yang tertata dengan baik membuat sebuah aplikasi lebih aman, stabil, dan mudah dikembangkan.
